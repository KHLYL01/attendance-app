# معهد الإمام الشافعي — نظام الحضور

نظام حضور وغياب داخلي للمعهد يعمل **بدون إنترنت بالكامل**. كل البيانات محفوظة على الجهاز في قاعدة بيانات SQLite، ولا يوجد أي خادم أو اتصال بالشبكة.

## الشاشات

| الشاشة | الوظيفة |
| --- | --- |
| الصفحة الرئيسية | عدد الطلاب والمستويات، حضور وغياب اليوم، نسبة حضور الشهر لكل مجموعة، الأكثر غياباً |
| الطلاب | إضافة وتعديل وحذف الطلاب، وصفحة لكل طالب فيها نسبة حضوره وغيابه في الشهر الحالي أو في مستواه الحالي |
| تسجيل الحضور | اختيار يوم الدوام والمستوى والمجموعة وتحديد حالة كل طالب (حاضر / غائب / متأخر / بعذر) ثم الحفظ |
| الإعدادات (زر الترس) | المستويات، أيام الدوام الأسبوعية، والعطل |
| السجلات | سجل الحضور مع فلترة بالفترة والمستوى والمجموعة والحالة، ملخص لكل طالب، واستيراد/تصدير Excel |

## الطلاب منفصلون عن السجلات

- الطلاب في جدول `students` والسجلات في جدول `attendance`.
- بيانات الطالب: الاسم، الرقم المميز، المستوى، والمجموعة (ذكور / إناث).
- **الرقم المميز يُعطى تلقائياً** (1001، 1002، …) عند الإضافة أو الاستيراد ولا يتكرر. سجلات الحضور في ملفات Excel ترتبط بالطالب عبر هذا الرقم فقط.
- المعهد يبدأ بثلاثة مستويات، ويمكن إضافة مستويات أو إعادة تسميتها من الإعدادات.
- إحصائيات "المستوى الحالي" تبدأ من أول سجل للطالب، وإذا نُقل إلى مستوى آخر تبدأ من يوم النقل.
- استيراد الحضور لا ينشئ طلاباً جدداً؛ أي رقم غير موجود يظهر في تقرير الاستيراد كسطر مرفوض.
- حذف طالب يحذف سجلاته معه.

## أيام الدوام والعطل

- من الإعدادات تختار أيام الدوام الأسبوعية (افتراضياً من السبت إلى الخميس) وتضيف العطل بفترات.
- لا يمكن تسجيل حضور في يوم ليس يوم دوام ولا في يوم لم يأتِ بعد، والاستيراد يرفض هذه الأيام.
- النسب لا تحسب إلا أيام الدوام؛ إذا أضيفت عطلة لاحقاً تُستبعد سجلاتها من النسب تلقائياً.

## قوالب Excel

من زر **Excel** في شاشة الطلاب أو شاشة السجلات:

1. **تحميل القالب** — ملف `.xlsx` فيه ورقة البيانات وورقة تعليمات.
2. املأ القالب في Excel أو Google Sheets واحفظه بصيغة `.xlsx`.
3. **استيراد من Excel** — يظهر بعده تقرير بعدد الأسطر المضافة والمحدّثة والمرفوضة مع سبب كل رفض.
4. **تصدير إلى Excel** — للحفظ في الجهاز أو المشاركة.

| القالب | الأعمدة (* إلزامي) | ملاحظات |
| --- | --- | --- |
| الطلاب | رقم الطالب، اسم الطالب *، المستوى *، المجموعة * | اترك الرقم فارغاً للطلاب الجدد فيُعطى تلقائياً؛ الرقم الموجود يحدّث بيانات الطالب |
| الحضور | رقم الطالب *، اسم الطالب، المستوى، المجموعة، التاريخ *، الحالة *، ملاحظات | يأتي معبّأً بطلاب المجموعة المختارة والتاريخ؛ الأسطر بلا حالة تُتجاهل |

- الحالة تقبل: `حاضر`، `غائب`، `متأخر`، `بعذر` أو اختصاراتها `ح`، `غ`، `ت`، `ع`.
- المستوى يقبل الاسم كاملاً (`المستوى الأول`) أو `الأول` أو رقمه `1`، والمجموعة تقبل `ذكور` أو `إناث`.
- التاريخ يقبل `2026-10-18` أو `18/10/2026` أو تاريخ Excel عادي.
- ملف تصدير الحضور فيه: ورقة **الحضور** (بنفس أعمدة القالب، يمكن تعديلها وإعادة استيرادها)، ورقة **الملخص** لكل طالب، وورقة **كشف الحضور** (الطلاب × الأيام).

## بنية المشروع

نفس بنية `car_care_app` (GetX + dartz):

```
lib/
  core/        animations, config, constant, di, extensions, localization,
               responsive, routes, theme, utils, widgets
  data/
    local/     app_database.dart (SQLite، الإصدار 3 مع ترقية تلقائية من الإصدارات السابقة)، failures.dart
    excel/     excel_workbook.dart (كتابة وقراءة xlsx)
    model/     student/ (الطالب، المستوى، المجموعة)، attendance/، calendar/ (أيام الدوام والعطل)، common/
    repo/      student_repository، attendance_repository، calendar_repository، excel_repository
  features/
    home/        الهيكل والتنقل بين الأقسام
    dashboard/   الصفحة الرئيسية
    students/    الطلاب
    attendance/  تسجيل الحضور اليومي
    records/     السجلات والملخص
    settings/    المستويات وأيام الدوام والعطل
```

## التشغيل

```bash
flutter pub get
flutter run
flutter test
```

المنصات المدعومة: Android وiOS، وكذلك Windows/Linux (عبر `sqflite_common_ffi`). الويب غير مدعوم لأن التخزين يعتمد على SQLite على الجهاز.
